## 目录结构

文件按原始 IMA 知识库的文件夹结构归类：根目录仅保留 32 个主题文件夹、`index.html` 总目录、`sprites/` 封面雪碧图与 `README.md`。

- 共 6349 个 HTML 页面，分布在 32 个顶层文件夹、143 个子文件夹中
- 每个文件夹对应知识库中的一个专题（如「半导体知库搭建资料」「13、半导体」「半导体&芯片」「光刻资料」等）
- 打开任意文件夹即可按专题浏览；`index.html` 为全库索引
