# 通用线性电子器件数据手册（第四册）· HTML 资料库

本仓库收录《通用线性电子器件数据手册4》（美国国家半导体公司编，赵志诚等译，科学出版社）的完整 HTML 数字化版本。

## 内容说明

- **128 页完整原页影像**：从原始扫描 PDF 直接提取 1952×2688 高清页面图，完整保留原书内容。
- **OCR 可搜索文字层**：每页提供 OCR 识别文字，可展开查看，并支持全库关键词检索定位页码。
- **阅读器功能**：左侧页码导航、全文搜索、当前页高亮、暗色模式、响应式布局。

## 目录结构

```
index.html          # 完整阅读器（含全部128页）

```

在线打开 `index.html` 即可阅读全部内容。
