# 半导体知库 · HTML 归档

本仓库是腾讯 IMA 知识库「半导体知库」的 HTML 版本归档，开源共享。

- **文件规模**：6361 个文件、159 个文件夹
- **生成方式**：通过 IMA 公开分享接口递归抓取全部文件元数据（标题、AI 摘要、解析正文、封面、来源路径），为每个文件生成一个结构化 HTML 页面

## 浏览

打开 [`index.html`](index.html) 查看完整索引，按文件夹分组，点击文件名进入详情页。每个详情页包含：

- AI 摘要
- IMA 解析出的正文内容
- 封面预览图
- 原始文件来源路径与查看链接
