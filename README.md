腾讯 IMA 知识库「半导体知库」的 HTML 版本归档，开源共享。

- **文件规模**：7019 个文件，6 大分类
- **升级内容**：原文首页影像升级为高清版（400×400，较旧版清晰度提升约 7 倍）；解析正文改为带分节标题的规整排版

- **06-书籍文献与知识库文档**：半导体书籍、高分文献、学习资料
